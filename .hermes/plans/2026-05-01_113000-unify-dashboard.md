## 3. Proposed Approach

### Phase 1: Fix WebSocket + API auth (P0)

**Root cause:** React dashboard gọi `/v1/ws/` và các endpoint `/v1/offers/`, `/v1/chat/` không auth. Registry API yêu cầu JWT.

**Fix options:**

**A. Public WS endpoint** — Tạo `/v1/ws/public` trong FastAPI registry, chỉ broadcast events không cần auth, dùng cho dashboard readonly. (Chỉnh backend FastAPI)

**B. Public API endpoints** — Đánh dấu `/v1/offers/`, `/v1/chat/`, `/v1/stats` là public-readonly (thêm `GET /v1/public/offers`, `GET /v1/public/chat`)

**C. Embed token in build** — Generate 1 token readonly scope, embed vào React build. Rủi ro bảo mật nếu token leak.

→ **Chọn A + B:** Tạo public endpoints readonly, không cần auth. Không rủi ro vì chỉ đọc.

### Phase 2: Link 2 site (P1)

**Fix đơn giản nhất:** Không cần code. Thêm cross-site links:

1. **Trên agentnet.io.vn**: Thêm link "Dashboard ↗" trong nav → `https://dashboard.agentnet.io.vn`
2. **Trên dashboard.agentnet.io.vn**: Thêm link "Home" hoặc "AgentNet" trong Sidebar → `https://agentnet.io.vn`

### Phase 3: Fix API 500 (P2)

Xác định endpoint nào gây 500, fix hoặc remove. Có thể là:
- `/v1/users/` (không tồn tại trong registry)
- `/v1/transactions/` (có thể cần payment service proxy)

### Phase 4: Merge 2 dashboard thành 1 (P3 — nice to have)

Tối ưu: Chỉ giữ 1 trong 2:
- Giữ React dashboard (dashboard.agentnet.io.vn) làm main — nó mạnh hơn
- Redirect agentnet.io.vn → dashboard.agentnet.io.vn
- Hoặc merge landing page của Flask vào React

→ Cần đánh giá thêm, không làm vội.

## 6. Risks

- **Public WS không rate-limited** → có thể bị spam. Fix: thêm rate limiter 10 connections/IP.
- **Public API endpoints expose agent data** → nhưng đây là marketplace, nên public là đúng. Chỉ cần filter sensitive fields (private keys).
- **2 dashboard tồn tại song song** → tạm thời chấp nhận, Phase 4 sẽ merge.
