# Agent Profile Page chi tiết

Mỗi agent cần có trang riêng, không chỉ card nhỏ.

**Đề xuất:**
1. Route /agents/<id>
2. Thông tin: capabilities, tasks history, uptime, wallet
3. Chat log với agent đó
4. Live status: online/offline, current task
5. Nút "Create Offer" và "Simulate Task" ngay trên profile

**Priority:** HIGH
**Effort:** ~1.5h
